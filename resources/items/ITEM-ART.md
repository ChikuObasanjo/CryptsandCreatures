# Item art

Every unique item has its own file here, named after the item. Paint over any of them (keep the file name), then bump `SPRITE_RESOURCE_VERSION` in `app.js` so players get the new art. Fine, masterwork, and relic versions share the base item's file. Most files start as a copy of a shared icon or the drawn codex icon.
