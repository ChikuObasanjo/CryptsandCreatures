Character Textures

Every part of the adventurer, as your paintings in art/character/ draw it. The paintings are the figure: there is no built-in drawing behind them. A card marked Not painted yet shows nothing for that part in the game until it has a painting.

To repaint a part, open its .dds (path on the card) in GIMP or Paint.NET, save, run npm run build, and reload. To start a new part, copy one that's close: npm run new-part -- weapon obsidian-glaive macuahuitl (or leave off the last name for a blank canvas with the alignment guide). The full guide is art/character/README.md.
