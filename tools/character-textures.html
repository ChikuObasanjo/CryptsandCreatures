Character Textures

Every part of the adventurer you can repaint, as the game draws it right now. Cards outlined in green use your texture from art/character/; the rest use the built-in drawing.

To repaint one: press its Download starter button, unzip it into art/character/ (it already has the right folder inside), edit the .dds in GIMP or Paint.NET, run npm run build, and reload this page or the game. Delete your file and build again to go back to the built-in drawing. The full guide is art/character/README.md.
