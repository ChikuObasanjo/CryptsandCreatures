Figure Art Workshop

Older tool. The easier way to repaint gear is now Character Textures (DDS files you edit in GIMP or Paint.NET). This SVG workshop still works; a DDS texture wins over an SVG drawing for the same part.

Redraw any part of the adventurer figure in Illustrator (or any SVG editor) and the game will use your drawing. Download a part's template, edit it, and save it as an SVG at the path shown on its card. Run npm run build (or Start Game.bat) and the game picks it up. Cards outlined in green already use your drawing.

  • Keep the 200 × 200 artboard. The figure faces east (right).
  • The faint figure in the reference layer is only a guide; the game ignores it, so leave it or delete it.
  • Outlines colored #2e211a are painted as ink lines. Every other color is painted as a watercolor wash.
  • These colors are swapped for the adventurer's own, so dyed clothing stays dyeable:
#ff00ff clothing dye #00ffff trim #ffff00 skin #00ff00 hair

Weapon templates are drawn upright, before the game tilts them into the hand, so the reference figure appears tilted in them.
